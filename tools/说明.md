# tools/ — 工具（机器部分）

正式工具：有版本、有 CLI 接口的成品。**律师不用管这个目录**，AI 会自己调用（双击也能用）。

## 住户

- `file2markdown/`：**文件转 Markdown**（Doc2MD）。Word / PDF / PPT / Excel 等转 md，docx 自动提取图片；独立 exe，**无需安装 Python**。用法见 `file2markdown/README.md`

## 纪律（AI 调用工具时必须遵守）

- 不读写 `guards/`、`画像.md`、`AGENTS.md`、`README.md`
- 产出写入 `知识/` 前须展示清单并经律师确认
- 只做转换 / 校验 / 搬运，不做判断
- 失败明确报错，不静默产出半成品
