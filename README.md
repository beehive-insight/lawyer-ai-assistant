# 你的 AI 律师助手包

这是一个属于你自己的 AI 助手包：把整个文件夹放进支持的 AI 工具（如 Trae），它就能带着你的资料和习惯帮你干活。

## 5 分钟上手

1. **解压**：把整个文件夹放进你的 AI 工具的工作目录。
2. **初始化**：打开 AI 工具，对它说「**初始化我的律师助手包**」，它会带你填画像、认识这个包。
3. **放材料**：把手头的资料放进 `知识/` 里对应的文件夹（保持原格式就行，Word、PDF、图片都可以）。
4. **开聊**：直接对话，比如「帮我整理一下这个案件的要素」。

## 我能帮你做什么

- **找类似案例**：描述案情，它去人民法院案例库找相似的判决（首次使用需要你登录一下案例库）
- **整理案件要素**：把一团乱麻的案情整理成要素表，标出风险和待补项
- **跟着流程干活**：你定的做事流程，它照着一步步来
- **陪你建新流程**：跟它说「帮我建个工作流」，它一步步问你然后写好给你确认

所有产出都是**草稿**，最终判断永远在你。

## 文件放哪（速查）

| 你手里的东西 | 放到 |
| --- | --- |
| 自己办的案的卷宗材料 | `知识/案件材料/`（一个案子一个文件夹） |
| 别人的、拿来参考的判决 | `知识/案例库/` |
| 你写好的文书成稿 | `知识/文书库/` |
| 空白 / 半成品模板 | `知识/模板库/` |
| 法条、司法解释、笔记 | `知识/法律资料/` |

## 机器部分不用管

带 `.` 开头的目录、`guards/`、`tools/`、`scripts/` 文件夹是机器部分：看得见，但不用管、别改、别删。

（`tools/` 里的工具帮你把 Word、PDF 转成 AI 好读的格式，AI 会自己调用，双击也能用，无需装任何东西。）

## 遇到问题

- AI 工具没识别出技能：换个支持技能目录的工具试试（Trae 可以），或按该工具的说明手动导入。
- 类案检索首次使用需登录人民法院案例库（rmfyalk.court.gov.cn），按提示登录一次即可。
- 想建工作流：直接跟 AI 说「帮我建个工作流」。
